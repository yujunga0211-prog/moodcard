# 무드카드 (MoodCard)

오늘의 기분을 일기로 쓰면, AI가 감정을 읽고 어울리는 노래 3곡과 그 기분을 표현한 짤을 카드 한 장으로 만들어 주는 기분 일기장입니다.

## 사용 흐름

1. 오늘의 일기를 씁니다.
2. AI가 감정을 분석합니다. (예: 불안 45% · 후련함 35% · 피곤함 20%)
3. 가사의 감정이 비슷한 노래 3곡을 추천받습니다.
4. AI가 그 기분을 표현한 짤을 만듭니다.
5. 감정 캘린더에 쌓이고, 링크나 인스타 스토리 크기(9:16) 카드로 공유합니다.
