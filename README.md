# 무드카드 (MoodCard)

> 오늘의 기분을 일기로 쓰면, AI가 감정을 읽고 어울리는 노래 3곡과 그 기분을 표현한 짤을 카드 한 장으로 만들어 주는 기분 일기장

| 이름 | 역할 |
| --- | --- |
| 유정아 (팀장) | 기획 · 구현 |
| 윤채원 | 데이터 · 평가 |

**기술 구성**
- **웹**: Next.js(App Router) + TypeScript + Tailwind CSS
- **DB**: Neon Postgres + pgvector (감정 벡터 검색)
- **로그인**: Auth.js + Google OAuth
- **AI**: OpenAI API — 감정 분석과 드립 문구(GPT), 짤 이미지(gpt-image 계열)
- **파일 저장**: Vercel Blob (짤·카드 이미지, SP3)
- **배포**: Vercel
- **개발 방식**: Claude Code로 구현, GitHub에서 기능별 브랜치와 PR로 관리

## 1. MVP 구현 계획 (SP2: 10/28 ~ 11/18)

### 목표

**11/18 데모에서 "일기 쓰기 → AI 감정 분석 → 노래 3곡 추천 → 캘린더에 저장 → 링크로 공유"가 배포된 사이트에서 처음부터 끝까지 동작하게 만듭니다.**

짤 생성과 카드 이미지는 SP3로 미루고, SP2에서는 서비스의 뼈대인 "감정 분석 + 노래 추천"에 집중합니다.

### 구현할 기능

| # | 기능 | 설명 | 완료 기준 |
| --- | --- | --- | --- |
| 1 | 구글 로그인 | Auth.js + Google OAuth로 로그인합니다. 첫 사용 때 "일기 내용은 감정 분석을 위해 AI 서비스로 전송됩니다"에 동의를 받습니다. | 로그인한 사용자는 자기 일기만 볼 수 있음 |
| 2 | 글 일기 쓰기 | 하루 한 편 글로 일기를 씁니다. 같은 날 다시 쓰면 그날 일기를 수정합니다. | 일기가 Neon DB에 저장되고 다시 열림 |
| 3 | AI 감정 분석 | OpenAI GPT 모델이 일기를 KOTE 기반 감정 약 30개 중에서 분류해 비율로 돌려줍니다(예: 불안 45% · 후련함 35% · 피곤함 20%). 정해진 감정 목록 안에서만 JSON으로 받습니다. | 결과 화면에 감정 상위 3개와 비율이 표시됨 |
| 4 | 노래 3곡 추천 (점수 공식 v1) | 일기 감정 벡터와 노래 가사 감정 벡터의 코사인 유사도(pgvector)로 후보를 찾고, 최근 추천곡 반복 벌점을 적용해 3곡을 고릅니다. 한국 노래 / 팝송 / 둘 다 중에서 고를 수 있습니다. | 곡마다 추천 이유("서운함·그리움이 비슷해요")와 유튜브·멜론 듣기 링크가 붙음 |
| 5 | 노래 데이터 구축 | 노래 목록을 만들고, 가사 감정을 LLM으로 한 번 분석해 **감정 벡터만** DB에 저장합니다. 가사 원문은 저장하지 않습니다. | SP2에는 최소 150곡(한국 100 + 팝송 50), SP3까지 450곡 |
| 6 | 감정 캘린더 | 날짜마다 그날 대표 감정의 색을 칠합니다(감정 30개를 8가지 색으로 묶음). 날짜를 누르면 그날 일기와 결과를 봅니다. | 한 달 달력에 감정 색이 표시됨 |
| 7 | 공유 링크 페이지 | 감정과 추천 노래만 담은 페이지(`/card/{id}`)를 로그인 없이 볼 수 있습니다. 일기 본문은 공유하지 않습니다. | 로그아웃 상태에서도 공유 링크가 열림 |
| 8 | 배포 | Vercel에 배포하고 Neon DB, 환경변수(OpenAI 키, 구글 OAuth, AUTH_SECRET)를 연결합니다. | 배포 주소에서 1~7이 모두 동작 |

| 위험 요소 | 가능성 / 영향 | 미리 하는 대비 | 문제가 생기면 |
| --- | --- | --- | --- |
| **노래 데이터 구축이 늦어짐** (가장 큰 위험) | 높음 / 높음 | 첫 주부터 노래 목록 작성을 시작하고, 매주 진행 곡 수를 확인 | 데모는 150곡으로 진행하고 나머지는 SP3에 추가. 그래도 부족하면 팝송 비중을 늘림 |

| LLM이 정해진 형식 밖의 답을 줌 | 중간 / 중간 | JSON 스키마를 지정한 구조화 출력 사용, 목록 밖 감정은 버림 | 한 번 다시 요청하고, 그래도 실패하면 "분석 실패, 다시 시도" 안내 |

| API 비용 초과 | 낮음 / 중간 | 사용자당 하루 분석 횟수 제한, 매주 사용액 확인 | 하루 전체 상한에 걸리면 안내 문구 표시 |

## 2. 완성본 구현 계획 (SP3: 11/25 ~ 12/09, 그리고 그 이후)

**목표: "일기 한 편 → 감정 분석 → 노래 추천 → AI 짤 → 인스타에 올릴 카드"까지 한 번에 되는, 매일 쓰고 싶고 친구에게 자랑하고 싶은 서비스**

### 핵심 기능 완성

| 기능 | 설명 |
| --- | --- |
| AI 기분 짤 생성 | 감정별 짤 구도 템플릿(동물·사물 캐릭터, 표정, 배경)과 LLM이 쓴 드립 문구로 이미지 생성 프롬프트를 만들고, OpenAI 이미지 생성 모델로 그린 그림 위에 문구를 얹습니다. 일기당 1장, 다시 만들기 하루 2번. 실존 인물은 생성하지 않습니다. |
| 인스타 스토리 카드 (9:16) | 감정·노래·짤을 담은 세로 카드를 이미지로 저장해 바로 인스타 스토리에 올립니다. 카드 디자인은 감정 색에 따라 바뀝니다. |
| 노래로 쓰는 일기 | 글 대신 "오늘의 노래" 한 곡과 한 줄 메모로 일기를 씁니다. |
| 추천 보정 (피드백 학습) | 추천곡의 맘에 들어요/별로예요와 노래로 쓴 일기를 모아, 노래의 감정 벡터와 사용자별 취향을 보정합니다. 쓸수록 나에게 맞는 추천이 됩니다. |
| 점수 공식 v2 | 감정 유사도 + 사용자 취향 + 최근 7일 기분 흐름 − 반복 벌점. 가중치는 사용자 조사 결과로 조정합니다. |
| 노래 450곡 | 한국 노래 300곡 + 팝송 150곡으로 확장합니다. |
| 월간 요약 | 이번 달 가장 많았던 감정, 감정 흐름 그래프, 이번 달의 노래를 보여 줍니다. |

### 야심찬 확장 목표

| 기능 | 설명 |
| --- | --- |
| 무드 결산 카드 | Spotify 연말 결산처럼 "이번 달 / 올해의 나" 결산 카드를 자동으로 만들어 공유합니다. (예: "11월의 당신은 '후련함'이 가장 많았어요. 이번 달의 노래는…") |
| 마스코트 캐릭터 | 무드카드 전용 캐릭터를 정해 모든 짤에 같은 캐릭터가 감정별 표정으로 등장하게 합니다. 서비스 정체성이 생깁니다. |
| 친구와 기분 나누기 | 친구를 추가하면 오늘 친구들의 기분 색과 노래를 볼 수 있습니다(일기 본문은 비공개). |
| 오늘의 기분 알림 | 앱처럼 설치(PWA)하고, 밤마다 "오늘 기분은 어땠나요?" 알림을 받습니다. 연속 기록 일수를 보여 줍니다. |
| 카카오 로그인 | 구글 계정이 없는 사용자를 위해 카카오 로그인을 추가합니다. |
| 기분 맞춤 플레이리스트 | 일주일치 추천곡을 모아 "이번 주 내 기분 플레이리스트"로 묶어 줍니다. |

### 평가와 성과 발표

| 대상 | 방법 | 지표 |
| --- | --- | --- |
| 감정 분석 | KOTE 시험 데이터 5천 개로 프롬프트 방식 3가지 비교 | 매크로 F1, 상위 3개 감정 적중률 |
| 노래 추천 | 무작위 추천 / 키워드 추천 / 우리 공식을 이름을 가리고 비교하는 사용자 조사(30명 이상) | "기분에 가장 맞는다" 선택 비율, 5점 만족도 |
| 피드백 보정 | 보정 전후 추천의 좋아요 비율 비교 | 좋아요 비율 변화 |
| 짤 | 템플릿 있는 짤과 없는 짤을 비교하는 "더 웃긴 짤" 투표(수업에서 만든 투표 앱 활용) | 선택 비율 |

평가 결과는 학술제 발표 또는 논문으로 정리합니다.
